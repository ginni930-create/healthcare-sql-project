## Project Summary
This project performs exploratory data analysis on healthcare patient data using SQL. The objective is to extract meaningful insights related to medical conditions, insurance providers, and billing patterns to support data-driven decision-making in a healthcare setting.
The analysis focuses on understanding cost distribution, identifying high-expense medical conditions, and evaluating insurance provider performance.

## Objectives
Analyze patient distribution across insurance providers
Identify medical conditions with the highest treatment costs
Evaluate billing patterns across different groups
Apply SQL aggregation techniques for business insights
Translate raw data into actionable healthcare insights

## Dataset Overview
The dataset contains anonymized healthcare records with the following attributes:
Patient Demographics (Gender, Age)
Medical Condition
Insurance Provider
Billing Amount
Admission Details
